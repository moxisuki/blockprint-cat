FEATURES

核心功能

一站式管理你的 Minecraft 蓝图——从本地文件到 3D 预览，从 PC 同步到社区探索。

本地蓝图管理

导入 .litematic / .schematic / .nbt / .json 文件，在手机上浏览、搜索、转换、重命名。

PC 端桥接同步

局域网实时连接 blockprint-link 模组，支持扫码配对与断点续传，双向同步蓝图。

实时 3D 预览

基于 Filament 的实时光线追踪渲染，支持镜头切换、光照预设、原版与模组方块。

WORKFLOW

使用流程

四步串联你的建造工作流，从导入到分享一气呵成。

01

导入蓝图

通过 SAF 文件选择器导入 .litematic / .schematic 等格式的蓝图文件。

02

3D 预览

加载原版或模组资源包，实时渲染方块模型，分层查看与镜头控制。

03

PC 同步

连接 PC 端 blockprint-link 模组，局域网传输蓝图，双向同步建筑方案。

04

社区探索

浏览 MCS / CMS 社区作品，按标签与热度搜索，一键下载心仪蓝图。
